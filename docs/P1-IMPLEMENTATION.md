# P1 功能与验收

本轮完成对照清单第 7–16 项，沿用原生 WPF 和受控 EPUB 模型，独立实现 Readest/calibre 的可取产品设计，未复制其 AGPL/GPL 应用代码，未加入新 NuGet 依赖。ReadEra 未提供可核验的官方开源应用代码，不能作为源码复用来源。

| 清单 | 实现 | 回归验证 |
| --- | --- | --- |
| 7 高亮、笔记与摘录 | 起止逻辑段/字符位置、原文校验、GUID、时间戳、四种颜色；编辑/定位/删除 | 跨样式、人工分段、组合字符/代理项/ZWJ emoji；WPF 编辑、重排、重开及删除持久化 |
| 8 长期逐书数据 | 索引与不可变逐书代次、惰性读取、旧书签迁移 | 超过 32 本仍保留书签；损坏单书不覆盖原数据，不影响其他书 |

## 使用

正文选中文字，在「批注」点击「选区高亮」，再编辑笔记和颜色。「书库」管理元数据、关联文件、导出和导入。移除书库条目要求确认，删除该条目的阅读数据，保留 EPUB 文件。

「清除最近记录」只清除快捷列表，再打开仍恢复位置/书签/批注。阅读状态由用户维护；打开未读书自动标为在读，已读标记保留。

「Aa」默认修改全局设置，勾选「仅此书外观」后独立保存。取消勾选或恢复默认重新继承全局。小说预设为衬线、大字号、两字缩进和两端对齐；文档预设为无衬线、左对齐、无缩进。代码保留空白和左对齐。

JSON 导入先显示新增/已有/冲突数量，以及笔记、位置、外观和元数据差异。「是」保留现有冲突值，「否」使用导入值，「取消」不写入。其他书签/批注合并，不按较高页码猜测更新方向。Markdown 为摘录阅读格式，JSON 为恢复格式，不能直接导入其他软件的私有格式。

整词规则：拉丁字母、数字、组合符和下划线属于连续词，汉字按字边界匹配，中英文交界允许词边界；带标点查询在相邻两侧都为连续词字符时才拒绝边界。没有正则表达式或网络索引。

SHA-256 识别字节完全相同的 EPUB，不是来源认证。同名但内容变化不自动合并。旧记录只有路径/长度/时间身份：先保存原数据，首次按旧身份打开或用户明确关联后升级为内容身份。

## 数据与事务

本机数据目录中，`state.json`（schema 2、32 本最近记录）与 `library.json`（schema 1）并存；`books/<内容身份>-<代次>.json`（schema 1）保存位置、书签、批注及外观。旧记录可读；升级后不要让旧版覆盖同一目录。

| 边界 | 上限 |
| --- | ---: |
| 书库 | 1,000 本、索引 4 MiB |
| 逐书数据 | 8 MiB、64 书签、128 批注 |
| 单条批注 | 摘录 4,096 字符、笔记 2,000 字符 |
| 元数据 | 书名/作者各 256 字符，16 个各 40 字符标签，100 字符系列 |
| JSON 备份/导入 | 16 MiB、深度 20；构造对象前检查集合/字符串预算 |
| 来源段落属性 | inline style 512 字符、缩进 0–4 em；不加载 CSS 文件 |

逐书代次先写入刷盘，再原子替换索引作为事务提交点，然后清理旧代次。写入失败撤销暂存文件；突然终止可能留下未被索引引用的文件，但不会暴露部分导入。旧最近记录迁移完成标记与索引一起提交，后续启动不重放旧记录，防止已移除书籍复活。备份完整数据后可清理孤立文件，不能删除索引引用的逐书文件。

外观值改变时立即标记待保存，100 ms 防抖只延迟排版；新增/编辑批注先校验候选数据再更新界面。保存携带编辑代次和书库变更版本，拒绝过期覆盖。失败显示「重试保存」；关闭失败询问保留窗口还是放弃未保存修改。注销/关机刷新失败时取消请求；挂起执行尽力刷新，断电无法保证尚未保存的修改。

## 验收边界

核心测试 95 项、Windows WPF 测试 40 项，由 CI 在 Linux/Windows 编译执行，并继续验证便携 EXE 双启动转交、依赖审计和 CodeQL。Linux 本地不能执行 WPF；结果与报告以最新 GitHub Actions 为准。

批注字素扫描使用固定 8,192 字符缓冲区、支持取消；字素组合超过 4,096 字符会拒绝创建。失配文字定位共享最多 1,600 万工作单位的扫描/候选校验预算；超额时保留旧位置比例回退或跳过无法验证的高亮，精确位置仍可使用。

范围定位针对当前文字模型，不实现跨软件 CFI 互通或修改后 EPUB 的模糊身份合并。超过全库备份上限时按单书导出。Windows 11 的 Narrator/NVDA、多 DPI、实际睡眠/断电和大书流畅度仍需真机验收。
