## 数据边界与兼容

单书数据从 2 MiB 调为 8 MiB，集合、字段长度及深度上限保留；索引仍为 4 MiB、备份仍为 16 MiB。最坏 Unicode 组合的测试 JSON 为约 5.73 MB。旧文件可读；新文件超过旧版上限时旧版无法读取，应避免旧版覆盖同一数据目录。全库备份超额时按单书导出。

字素组合超过 4,096 字符会拒绝创建批注，避免巨型组合字符要求无界缓冲区。扫描保持完整字素边界，不在块尾丢掉区域指示符、ZWJ 或组合符的上下文。

定位回退预算为 1,600 万工作单位，计入复制/扫描字符和候选上下文校验。超过预算不尝试猜测高亮；阅读位置仍有既有比例回退。该预算保护陈旧定位的工作量，不是总进程内存上限。
