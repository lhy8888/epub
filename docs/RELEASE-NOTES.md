QuietRead · 静读首版，面向 Windows 11 x64 的本地 EPUB 2/3 阅读器。

下载 `QuietRead-0.1.0-Windows-x64.zip`，完整解压后双击 `QuietRead.exe`。无需安装 .NET 或管理员权限。包内 `samples/QuietRead-Guide.epub` 可用于体验。

支持目录、搜索、书签、最近阅读、主题、阅读外观和按钮全屏；采用原生 WPF 受控排版及受限资源读取。原书 CSS、嵌入字体、复杂 SVG、DRM、固定版式暂不支持。

ZIP 旁的 `.zip.sha256` 用于核对完整性。二进制未做 Authenticode 签名；哈希不能证明发布者身份。Hosted Windows runner 的自动测试不代替 Windows 11 真机性能/DPI 验收。

功能与使用说明见 [README](https://github.com/lhy8888/epub#readme)，完整记录见 [CHANGELOG](https://github.com/lhy8888/epub/blob/main/CHANGELOG.md)。
